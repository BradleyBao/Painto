# Welcome to Painto! 
Painto is a lightweight on-screen annotation app for **Windows**, built with [WinUI3](https://github.com/microsoft/microsoft-ui-XAML). Draw over and annotate your desktop during presentations, lessons, and screen sharing. <br><br>
<a href="https://apps.microsoft.com/detail/9p7g2qf10wrb?mode=direct">
	<img src="https://get.microsoft.com/images/en-us%20dark.svg" width="200"/>
</a>

## Features 
- Draw and annotate your screen in real time
- Easily switch screen mode / drawing mode 
- Customize pens (color and thickness)
- Draw across multiple monitors or on a selected monitor
- Erase individual strokes or portions of a stroke
- Switch tools with customizable keyboard shortcuts
- Modern design, aligned with Windows 11

## Quick Start
1. Download the app from [official website](https://painto.tianyibrad.com/) or [MS Store](https://apps.microsoft.com/detail/9p7g2qf10wrb?mode=direct)
2. Starting drawing with Pen Mode (default is Pen Mode)
3. When you want to switch to PC Mode, click the "cursor" button
4. To quit the application, click the red "Cross" button
5. To add / remove Pens, click the plus / minus button
6. To modify a Pen, double-click the target pen in the tool bar
7. To erase the ink, click the "eraser" button
8. For more settings, click the "Setting" button
